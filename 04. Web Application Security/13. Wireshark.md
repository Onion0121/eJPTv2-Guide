# Wireshark

Wireshark is the most widely used network protocol analyzer in the world. It allows penetration testers, network administrators, and security analysts to capture and inspect network traffic in real time. During the **INE eJPT** exam, Wireshark can be extremely useful for analyzing network communications, identifying credentials transmitted in cleartext, understanding protocols, and troubleshooting connectivity issues.

Unlike Nmap or Metasploit, Wireshark is a passive analysis tool—it does not attack targets but instead captures and analyzes packets moving across the network.

---

# Capture vs Display Filters

| Capture Filter | Display Filter |
|----------------|----------------|
| Applied before capture | Applied after capture |
| Uses libpcap syntax | Uses Wireshark syntax |
| Reduces captured traffic | Filters existing packets |
| Cannot recover discarded packets | Can be modified anytime |

# Common Mistakes

Avoid these mistakes:

- Capturing on the wrong interface.
- Confusing capture filters with display filters.
- Forgetting to follow TCP streams.
- Ignoring HTTP POST requests.
- Focusing only on encrypted traffic.
- Forgetting to export downloaded files.

---

# eJPT Tips

During the **INE eJPT** exam:

- Use Wireshark to analyze provided packet captures (PCAPs).
- Look for credentials transmitted in cleartext via HTTP, FTP, or Telnet.
- Use **Follow TCP Stream** to reconstruct complete conversations.
- Filter traffic by protocol or IP address to reduce noise.
- Inspect DNS requests to identify internal hosts and services.
- Export HTTP objects if files have been transferred.
- Understand the difference between capture filters and display filters.

# Summary

Wireshark is an essential packet analysis tool used to inspect network communications and troubleshoot network issues. It enables penetration testers to analyze protocols, identify plaintext credentials, reconstruct application sessions, inspect DNS queries, recover transferred files, and better understand network behavior. During the **INE eJPT** exam, proficiency with display filters, TCP stream analysis, and protocol inspection can provide valuable information that supports enumeration, credential discovery, and overall penetration testing activities.
