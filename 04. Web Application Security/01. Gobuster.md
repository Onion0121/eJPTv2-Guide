# Gobuster

Gobuster is one of the most popular tools for content discovery during web application penetration testing. It performs brute-force attacks against web servers to discover hidden directories, files, virtual hosts (vHosts), DNS subdomains, and Amazon S3 buckets.

Directory and file enumeration is one of the first steps during a web assessment because developers often leave sensitive resources exposed that are not linked from the main website.

Gobuster is fast, simple, and heavily used during the **INE eJPT** exam.

---

# Installation

Gobuster comes pre-installed on Kali Linux.

Verify the installation:

```bash
gobuster version
```

Install manually:

```bash
sudo apt install gobuster
```

---

# Basic Syntax

```bash
gobuster MODE [options]
```

Example:

```bash
gobuster dir \
-u http://TARGET \
-w /usr/share/wordlists/dirb/common.txt
```

---

# Gobuster Modes

Gobuster supports multiple enumeration modes.

| Mode | Description |
|-------|-------------|
| dir | Directory and file enumeration |
| dns | DNS subdomain brute forcing |
| vhost | Virtual Host enumeration |
| fuzz | Parameter fuzzing (newer versions) |
| s3 | Amazon S3 bucket enumeration |
| gcs | Google Cloud Storage enumeration |


# Choosing a Wordlist

Common Kali wordlists:

```bash
/usr/share/wordlists/
```

Useful options:

```
dirb/common.txt

dirbuster/directory-list-2.3-small.txt

dirbuster/directory-list-2.3-medium.txt

rockyou.txt
```

Recommended:

| Wordlist | Speed | Coverage |
|----------|-------|----------|
| common.txt | Very Fast | Small |
| directory-list-2.3-small.txt | Fast | Good |
| directory-list-2.3-medium.txt | Medium | Better |
| directory-list-2.3-big.txt | Slow | Excellent |

# Ignore SSL Errors

For HTTPS targets with invalid certificates:

```bash
gobuster dir \
-k \
-u https://TARGET \
-w WORDLIST
```

---

# Add File Extensions

Search for PHP files:

```bash
gobuster dir \
-u http://TARGET \
-w WORDLIST \
-x php
```

Multiple extensions:

```bash
-x php,txt,bak,zip,html
```

Useful extensions:

```
php
asp
aspx
jsp
txt
bak
old
zip
tar
sql
conf
xml
```

# Recursive Enumeration

Gobuster itself does not perform true recursive enumeration like Feroxbuster.

Instead, enumerate discovered directories manually.

Example:

```
/admin
```

Then scan again:

```bash
gobuster dir \
-u http://TARGET/admin \
-w WORDLIST
```

---

# Hide Specific Status Codes

Ignore 404 responses:

```bash
gobuster dir \
-u http://TARGET \
-w WORDLIST \
-b 404
```

Ignore multiple codes:

```bash
-b 404,403
```

---

# Show Only Specific Status Codes

Example:

```bash
-s 200,301,302,403
```

Useful during enumeration.

---

# Increase Threads

Default:

```bash
-t 10
```

Example:

```bash
-t 50
```

Higher threads:

- Faster scans
- More bandwidth usage
- Higher chance of detection

---

# Change User-Agent


Useful when websites block default scanners.

# Virtual Host Enumeration

Discover hidden virtual hosts:

```bash
gobuster vhost \
-u http://TARGET \
-w WORDLIST
```

Useful when multiple websites share the same IP address.

Example:

```
admin.target.local

dev.target.local

test.target.local
```

---

# DNS Enumeration

Discover subdomains:

```bash
gobuster dns \
-d target.com \
-w WORDLIST
```

Example output:

```
mail.target.com

vpn.target.com

dev.target.com

admin.target.com
```

# HTTP Status Codes

| Code | Meaning |
|------|---------|
| 200 | Resource found |
| 204 | Empty response |
| 301 | Permanent redirect |
| 302 | Temporary redirect |
| 307 | Temporary redirect |
| 401 | Authentication required |
| 403 | Forbidden |
| 500 | Internal server error |

A **403 Forbidden** response often indicates that the resource exists but access is denied, making it a valuable finding during enumeration.

# Typical eJPT Workflow

Start with a small wordlist:

```bash
gobuster dir \
-u http://TARGET \
-w /usr/share/wordlists/dirb/common.txt
```

If interesting directories are found:

- Enumerate them individually.
- Search for backup files.
- Look for configuration files.
- Check upload directories.
- Test login portals.

If nothing useful is found:

- Switch to a larger wordlist.
- Add file extensions.
- Test virtual hosts.
- Enumerate subdomains.

# Common Mistakes

Avoid these mistakes:

- Using only one wordlist.
- Ignoring 403 responses.
- Forgetting to search for file extensions.
- Not enumerating discovered directories.
- Ignoring redirects.
- Scanning too aggressively and triggering rate limits.
- Forgetting to test authenticated areas with cookies.

---

# eJPT Tips

During the **INE eJPT** exam:

- Always perform directory enumeration on every web server.
- Use multiple wordlists if the first scan yields few results.
- Test common extensions such as `.php`, `.txt`, `.bak`, `.zip`, and `.sql`.
- Investigate every `200`, `301`, `302`, and `403` response.
- Save your results for later analysis.
- Combine Gobuster with tools like **Burp Suite**, **Nikto**, **Wfuzz**, and **Nmap** to build a complete picture of the target.

# Cheat Sheet

```bash
# Basic directory scan
gobuster dir -u http://TARGET -w WORDLIST

# HTTPS
gobuster dir -k -u https://TARGET -w WORDLIST

# PHP files
gobuster dir -u http://TARGET -w WORDLIST -x php

# Multiple extensions
gobuster dir -u http://TARGET -w WORDLIST -x php,txt,bak,zip

# Increase threads
gobuster dir -u http://TARGET -w WORDLIST -t 50

# Ignore 404
gobuster dir -u http://TARGET -w WORDLIST -b 404

# Show only 200,301,302,403
gobuster dir -u http://TARGET -w WORDLIST -s 200,301,302,403

# Virtual hosts
gobuster vhost -u http://TARGET -w WORDLIST

# DNS enumeration
gobuster dns -d target.com -w WORDLIST

# Custom headers
gobuster dir -u http://TARGET -w WORDLIST -H "Authorization: Bearer TOKEN"

# Cookies
gobuster dir -u http://TARGET -w WORDLIST -c "PHPSESSID=value"

# Save output
gobuster dir -u http://TARGET -w WORDLIST -o results.txt
```

# Summary

Gobuster is an essential content discovery tool for penetration testers and one of the first utilities you should run against any web application. By combining directory brute-forcing, virtual host enumeration, DNS discovery, and file extension testing, Gobuster helps uncover hidden attack surfaces that are often missed during manual browsing. Mastering Gobuster, along with Burp Suite and Wfuzz, will significantly improve your web reconnaissance skills and prepare you for the web application scenarios commonly encountered in the **INE eJPT** exam.
