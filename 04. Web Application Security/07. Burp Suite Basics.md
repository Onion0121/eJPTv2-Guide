# Burp Suite Basics

Burp Suite is one of the most widely used web application security testing tools. It acts as an intercepting proxy between your browser and the target web application, allowing you to inspect, modify, and replay HTTP requests and responses. It is an essential tool for web penetration testing and is heavily used throughout the **INE eJPT** learning path.

---

# What is Burp Suite?

Burp Suite sits between your browser and the target server.

```
Browser

↓

Burp Proxy

↓

Target Web Server

↓

Burp Proxy

↓

Browser
```

Instead of sending requests directly to the server, every request passes through Burp Suite first.

---

# Why Use Burp Suite?

Burp allows penetration testers to:

- Intercept HTTP requests
- Modify requests before sending them
- Analyze server responses
- Discover hidden parameters
- Test authentication
- Bypass client-side validation
- Manipulate cookies
- Identify vulnerabilities
- Automate attacks

# Burp Certificate

To inspect HTTPS traffic:

Open:

```
http://burp
```

Download:

```
CA Certificate
```

Import the certificate into your browser's trusted certificate store.

Without this certificate, HTTPS requests will generate certificate warnings.

# Common Vulnerabilities Found

Burp Suite helps identify:

- SQL Injection
- File Upload Vulnerabilities
- Local File Inclusion (LFI)
- Authentication Bypass
- Session Management Issues
- IDOR
- Weak Access Controls
- Command Injection
- Parameter Tampering

---

# Common Mistakes

Avoid these mistakes:

- Forgetting to install the Burp CA certificate.
- Leaving **Intercept** enabled while browsing.
- Ignoring HTTP History.
- Testing only GET requests.
- Forgetting to inspect cookies and hidden parameters.
- Not adding the target to scope.

---

# eJPT Tips

During the **INE eJPT** exam:

- Use Burp Suite for every web application.
- Intercept login requests and inspect all parameters.
- Modify cookies and hidden fields to test authorization.
- Save interesting requests to **Repeater** for manual testing.
- Send repetitive attacks to **Intruder**.
- Use **Decoder** when handling encoded values.
- Review **HTTP History** frequently to avoid missing hidden endpoints.

# Summary

Burp Suite is the primary tool for manual web application penetration testing. Acting as an intercepting proxy, it enables security professionals to inspect, modify, replay, and analyze HTTP traffic between the browser and the target application. Mastering the **Proxy**, **Target**, **Repeater**, **Intruder**, and **Decoder** modules is essential for discovering and exploiting common web vulnerabilities. During the **INE eJPT** exam, Burp Suite should be your default tool for assessing every web application you encounter.
