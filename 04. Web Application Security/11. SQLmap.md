# SQLmap

SQLmap is the most popular open-source tool for automating the detection and exploitation of SQL Injection (SQLi) vulnerabilities. It can identify vulnerable parameters, fingerprint the database, enumerate tables and users, dump data, obtain database shells, and even execute operating system commands when supported by the target database.

Although understanding **manual SQL Injection** is essential, SQLmap can significantly speed up exploitation once a vulnerability has been confirmed. During the **INE eJPT** exam, you should first verify SQL Injection manually using **Burp Suite** before relying on SQLmap.

---

# What is SQLmap?

SQLmap automates SQL Injection attacks.

```
Target URL

↓

SQLmap

↓

Detect SQL Injection

↓

Identify Database

↓

Enumerate Information

↓

Extract Data

↓

Post Exploitation
```

# Installation

Kali Linux includes SQLmap by default.

Verify installation:

```bash
sqlmap --version
```

If needed:

```bash
sudo apt update

sudo apt install sqlmap -y
```

---

# Basic Syntax

```bash
sqlmap -u URL [OPTIONS]
```

Example:

```bash
sqlmap -u "http://TARGET/page.php?id=1"
```

---

# Detect SQL Injection

Basic scan:

```bash
sqlmap -u "http://TARGET/page.php?id=1"
```

SQLmap automatically tests:

- Boolean-Based
- Error-Based
- UNION-Based
- Time-Based
- Stacked Queries

---

# Batch Mode

Avoid interactive questions:

```bash
sqlmap -u "http://TARGET/page.php?id=1" --batch
```

Useful during long scans.

# Common Mistakes

Avoid these mistakes:

- Running SQLmap before manually confirming SQL Injection.
- Forgetting to specify cookies for authenticated pages.
- Testing every parameter unnecessarily.
- Using maximum risk and level without reason.
- Ignoring SQLmap session files.
- Forgetting to use `-r` for complex POST requests.

---

# eJPT Tips

During the **INE eJPT** exam:

- Always confirm SQL Injection manually with **Burp Repeater** first.
- Use `--batch` to automate prompts.
- Enumerate databases before dumping tables.
- Use `-r request.txt` for login forms or authenticated requests.
- Start with the default settings and increase `--level` and `--risk` only if needed.
- Combine SQLmap with Burp Suite for the most efficient workflow.

# Summary

SQLmap is the industry-standard tool for automating SQL Injection detection and exploitation. It can identify vulnerable parameters, fingerprint database management systems, enumerate databases, tables, users, and columns, extract sensitive information, and, in some cases, gain operating system access. While SQLmap is extremely powerful, professional penetration testers should first confirm SQL Injection manually before automating exploitation. Mastering SQLmap alongside Burp Suite provides an efficient workflow for exploiting SQL Injection vulnerabilities during both real-world engagements and the **INE eJPT** certification exam.
