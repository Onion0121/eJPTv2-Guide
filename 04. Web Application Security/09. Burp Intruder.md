# Burp Intruder

Burp Intruder is Burp Suite's automated request engine used to send large numbers of HTTP requests with different payloads. It is primarily used for brute-force attacks, fuzzing, parameter discovery, authentication testing, ID enumeration, and vulnerability discovery.

Unlike **Repeater**, which is designed for manual testing, **Intruder** automates repetitive attacks by replacing selected parts of a request with predefined payloads.

The **Community Edition** throttles Intruder attacks, but it remains more than sufficient for the **INE eJPT** exam.

---

# What is Burp Intruder?

Intruder automatically sends multiple modified HTTP requests.

```
Captured Request

↓

Send to Intruder

↓

Select Payload Positions

↓

Load Payloads

↓

Launch Attack

↓

Analyze Results
```

Instead of manually changing a parameter hundreds of times, Intruder performs the work automatically.

# Attack Types

Burp Intruder supports four attack modes.

---

## Sniper

Changes one payload position at a time.

Example:

```
username=admin

password=password
```

Payloads:

```
admin

administrator

root
```

Only one parameter changes during each request.

Best for:

- Fuzzing
- SQL Injection
- LFI
- Command Injection
- Parameter discovery

---

## Battering Ram

Uses the same payload in every marked position.

Example:

```
username=admin

password=admin
```

Useful when identical values are required.

---

## Pitchfork

Uses multiple payload lists simultaneously.

Example:

```
Username List

↓

admin

john

alice
```

```
Password List

↓

admin123

password

secret
```

Requests become:

```
admin : admin123

john : password

alice : secret
```

---

## Cluster Bomb

Tests every possible combination.

Example:

Users:

```
admin

john
```

Passwords:

```
123456

password

admin123
```

Requests:

```
admin:123456

admin:password

admin:admin123

john:123456

john:password

john:admin123
```

Produces many requests.

---

# Selecting Payload Positions

Intruder automatically highlights parameters.

Example:

```http
POST /login

username=admin

password=password
```

Mark:

```
§admin§

§password§
```

These values will be replaced by payloads.

# Intruder vs Repeater

| Repeater | Intruder |
|-----------|-----------|
| Manual | Automated |
| One request at a time | Hundreds or thousands of requests |
| Precise testing | Large-scale fuzzing |
| Better for validation | Better for discovery |

Normally:

```
Intruder

↓

Find Interesting Response

↓

Repeater

↓

Confirm Vulnerability
```

# Common Mistakes

Avoid these mistakes:

- Selecting the wrong attack type.
- Replacing too many parameters simultaneously.
- Ignoring response length differences.
- Using extremely large payload lists unnecessarily.
- Forgetting to sort results.
- Looking only at HTTP status codes.

---

# eJPT Tips

During the **INE eJPT** exam:

- Use **Sniper** for SQL Injection, LFI, and parameter fuzzing.
- Use **Cluster Bomb** only when both usernames and passwords are unknown.
- Sort results by **Length** and **Status** to quickly identify anomalies.
- Combine Intruder with **Repeater** to manually validate successful findings.
- Keep payload lists small and focused to save time during the exam.

# Summary

Burp Intruder is Burp Suite's automated attack module for sending large numbers of modified HTTP requests. It is commonly used for brute-force attacks, fuzzing, parameter discovery, authentication testing, and identifying vulnerabilities such as SQL Injection, Local File Inclusion, and IDOR. By selecting the appropriate attack type, configuring targeted payloads, and carefully analyzing response status codes, lengths, and timing differences, penetration testers can efficiently discover weaknesses that would be difficult to identify manually. Mastering Burp Intruder is an important skill for both professional web application assessments and the **INE eJPT** certification exam.
