# Recommended Websites

The cybersecurity community offers an incredible number of free and paid resources for learning penetration testing. This page contains the websites that I personally recommend for preparing for the **INE eJPT** certification and continuing toward certifications like **eCPPT**, **PNPT**, **CRTO**, and **OSCP**.

The websites are grouped by category so you can easily find the right resource depending on what you're studying.

---

# Learning Platforms

## INE

**https://ine.com**

The official training platform for the eJPT and eCPPT certifications.

Recommended for:

- eJPT
- eCPPT
- Hands-on Labs
- Skill Checks
- CTFs
- Learning Paths

---

## TryHackMe

**https://tryhackme.com**

One of the best platforms for beginners.

Recommended Learning Paths:

- Pre Security
- Complete Beginner
- Jr Penetration Tester
- Offensive Pentesting
- Web Fundamentals

Excellent for learning:

- Linux
- Networking
- Enumeration
- Metasploit
- Web Security

---

## Hack The Box

**https://www.hackthebox.com**

A realistic penetration testing platform.

Includes:

- Machines
- Sherlocks
- Challenges
- Academy
- Pro Labs

Excellent after completing the eJPT.

---

## PortSwigger Web Security Academy

**https://portswigger.net/web-security**

The best free website for learning web application security.

Topics include:

- SQL Injection
- XSS
- CSRF
- Authentication

- XXE

- Burp Suite

Highly recommended before taking the eJPT.

# Essential Bookmarks

---

# Final Thoughts

Cybersecurity is a rapidly evolving field, and staying up to date is just as important as mastering technical skills. Make a habit of reading documentation, following trusted security researchers, and practicing regularly on hands-on platforms.

This collection of websites will serve as a valuable reference throughout your penetration testing journey—from preparing for the **eJPT** to tackling advanced certifications and real-world engagements.
